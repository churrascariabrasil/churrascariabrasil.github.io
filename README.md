# Churrascaria Brasil (BR5) — página de links e cardápio

Site estático publicado no GitHub Pages: https://churrascariabrasil.github.io/

## Atualizar preços ou itens
1. Edite `_gerador/data.py`.
2. Rode `python3 _gerador/build.py` (Python 3, sem dependências).
3. Faça commit dos arquivos gerados na raiz.

A pasta `_gerador/` não é publicada pelo GitHub Pages.
